# Отчёт о датасете payments.csv

## Что делает проект
Класс `DataFrameReporter` анализирует таблицу платежей и выводит отчёт:
- размер данных (строки и столбцы);
- количество и долю дубликатов;
- описательную статистику числовых столбцов;
- количество пропущенных значений по каждому столбцу.
